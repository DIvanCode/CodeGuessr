# CodeGuessr

CodeGuessr — веб-игра, в которой нужно угадывать GitHub-репозиторий по фрагментам из его кода. Игроку даётся несколько раундов, количество очков за каждый зависит от точности ответов.

[Презентация CodeGuessr](https://docs.google.com/presentation/d/14zROH4BuQ9Qqv-k1ehzWo80LPkf9gRid/edit?usp=sharing&ouid=102720741115620142705&rtpof=true&sd=true)

## Возможности

- Просмотр фрагментов кода из репозитория с подсветкой синтаксиса.
- Просмотр графа вызовов функций в демо и в коде из GitHub. Для связей между файлами дополнительно загружается до шести небольших исходников; это ограниченный граф выбранных файлов, а не полный индекс репозитория.
- Поиск репозитория по названию или выбор его расположения на интерактивной карте как в GeoGuesser.
- Угадывание доп. информации об репозиториях: год создания, число звёзд и используемые языки программирования.
- Подсказки за очки и результаты после каждого раунда.
- Готовая демо-карта и собственные карты по публичным репозиториям пользователя или организации GitHub.

## Установка и запуск

Нужны Docker и Docker Compose. Для публичного HTTPS домен должен указывать на сервер, а TCP-порты `80` и `443` должны быть открыты.

```bash
git clone https://github.com/DIvanCode/CodeGuessr.git
cd CodeGuessr
cp .env.example .env
chmod 600 .env
```

В `.env` укажите `DOMAIN` (например, `guessr.example.com`, без `https://`). Для запуска на `localhost` можно оставить `DOMAIN=localhost`, но браузер может не доверять локальному сертификату Caddy. `GITHUB_TOKEN` необязателен, без него демо работает, но запросы к GitHub API ограничены. Токен не нужно добавлять в Git.

```bash
docker compose up --build -d --wait
```

Сайт будет доступен по `https://<ваш-домен>/`, проверка API — по `/api/health/ready`. Caddy автоматически настраивает HTTPS, Nginx отдаёт фронтенд и проксирует запросы к FastAPI.

## Уровни сложности

Сложность переключается в шапке и начинает новую игру в текущем режиме.

| Уровень | Карта | Своя карта | Задание |
| --- | --- | --- | --- |
| Лёгкий | материк → репозиторий | до 20 репозиториев | 2 файла по 60 строк |
| Средний | материк → группа → репозиторий | до 80 репозиториев | 3 файла по 60 строк |
| Сложный | материк → группа → репозиторий → папка | до 300 репозиториев | 4 файла по 70 строк из одной папки |

Границы следующего уровня появляются при приближении, как в GeoGuessr. Клик выбирает самый глубокий видимый уровень. Очки за место — максимум из двух величин: очков за угаданный уровень (вплоть до 5000 за точное попадание) и очков за расстояние до ответа. В демо группы — семейства языков, на своей карте — основной язык репозитория. Папки — каталоги, где репозиторий начинает ветвиться; они загружаются из GitHub при приближении к стране. Средний и сложный уровни демо берут код из GitHub, поэтому им нужна сеть. Подсказка пути на сложном уровне стоит 1500, потому что выдаёт папку.

## Своя карта по GitHub

Вставьте в поле «Своя карта» ссылку на пользователя или организацию GitHub, например `https://github.com/pallets`. Backend загрузит до 20, 80 или 300 публичных репозиториев владельца в зависимости от сложности без форков и построит из них новую карту. Материки — тематические кластеры: по названию, описанию и topics репозиториев строится TF-IDF, и репозитории делятся на 1–6 групп похожих проектов (bisecting k-means, примерно √N материков). Название материка — самые характерные слова кластера, например «bot · telegram». Названия языков, служебные слова и имя владельца в признаки не входят, поэтому материк угадывается по смыслу кода, а не по синтаксису. Репозитории без описания и topics попадают туда, где больше всего проектов на том же языке. На среднем и сложном уровнях группами внутри материка служат основные языки, редкие собираются в «Другие языки». Если тематических материков получилось меньше трёх, а основных языков больше, оси меняются местами: материки строятся по основному языку (до пяти языков плюс «Другие языки»), а группами служат найденные темы. Так карта небольших организаций не превращается в один-два материка. Фрагменты кода, доли языков, звёзды и год создания берутся из GitHub в момент начала раунда.

Без токена GitHub API разрешает 60 запросов в час с одного IP. Создание карты стоит 2–4 запроса, каждый раунд — запросы за фрагментами кода, до шести дополнительных исходников для графа и метаданными, а на сложном уровне каждое приближение к новой стране — ещё 1–2. Чтобы поднять лимит, укажите в `.env` персональный токен в `GITHUB_TOKEN`; права ему не нужны.
