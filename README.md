# CodeGuessr

Угадайте репозиторий GitHub по демонстрационному фрагменту кода. В каждом из пяти раундов сначала выберите страну на карте или найдите проект через поиск. Затем можно указать год, диапазон звёзд и доли языков на круговой диаграмме.

## Развёртывание через Docker Compose (HTTPS)

Caddy — единственный публичный контейнер, слушает TCP `80`/`443` и UDP `443`, автоматически выпускает и продлевает сертификат и перенаправляет HTTP на HTTPS. Nginx внутри контейнера фронтенда слушает порт `80`, отдаёт собранный React и проксирует `/api/` в FastAPI. Backend слушает `8000` **только в Docker-сети**: порты `8000` и `5173` наружу не публикуются. Между Caddy и FastAPI нет прямого подключения — только через фронтенд. Контейнер бэкенда запускается без root, с read-only файловой системой и без Linux capabilities.

1. Создайте DNS-запись `A` (и `AAAA`, если используете IPv6) для домена, направленную на IP сервера. Разрешите входящие TCP-порты `80`, `443`; UDP `443` необязателен (HTTP/3). Убедитесь, что другой сервис не занимает TCP `80`/`443`.
2. Создайте `.env` **только на сервере**, заполните свой домен и, при желании, GitHub-токен. Не добавляйте `.env` в Git:

   ```bash
   cp .env.example .env
   chmod 600 .env
   # Отредактируйте .env: DOMAIN=guess.example.com, GITHUB_TOKEN=...
   ```

   `DOMAIN` — только имя хоста без протокола и слеша. `GITHUB_TOKEN` можно оставить пустым: демо работает без токена, а публичный GitHub API ограничивает неавторизованные запросы до 60 в час с IP сервера. С токеном типичный лимит — 5000 в час. Для доступа к публичным репозиториям достаточно read-only fine-grained PAT, без прав на запись. Если токен задан, он передаётся **только бэкенду**, а не браузеру, Nginx или Caddy. В `.env.example` настоящих секретов нет.
3. Запустите приложение из корня репозитория:

   ```bash
   docker compose config --quiet
   docker compose up --build -d --wait --remove-orphans
   ```

4. Проверьте `https://<ваш-домен>/` и `https://<ваш-домен>/api/health/ready`. При проблемах с сертификатом проверьте DNS, доступность порта 80 извне и `docker compose logs caddy`.

Caddy хранит сертификаты в томах `caddy_data` и `caddy_config`. Не удаляйте их при обычном обновлении (`docker compose down -v` удалит тома). Для локальной проверки можно оставить `DOMAIN=localhost` и открыть `https://localhost/`; Caddy использует локальный CA, которому браузер по умолчанию не доверяет. Не используйте `curl -k` на production-сайте: он нужен только в CI для локального самоподписанного сертификата.

**Секреты и ограничения:** в текущей версии CodeGuessr PostgreSQL отсутствует, поэтому `DB_PASSWORD`, `DATABASE_URL` и прочие креды БД не нужны. Состояние раундов хранится в памяти FastAPI и теряется при перезапуске контейнера; постоянную БД можно добавить отдельно, когда появится необходимость. Docker Compose получает `GITHUB_TOKEN` из серверного `.env`, а Docker хранит переданные переменные окружения в метаданных контейнера, доступных администраторам Docker — ограничьте доступ к серверу и Docker socket. Используйте отдельный токен с минимальными правами и сроком действия, периодически его меняйте. Не кладите токен в исходники, Vite-переменные (`VITE_*`) или JS-бандл.

Каталог хранится в `Backend/app/data/catalog.json`. Все 100 репозиториев нанесены на шесть тематических материков. У каждого есть условный `size_mb` в мегабайтах. Материки делятся прямыми границами на страны, площадь которых пропорциональна квадратному корню из размера в пределах материка. Это оставляет маленькие страны кликабельными.

В `Backend/app/data/demo.json` находятся заготовленные фрагменты и ответы для 12 проектов. Игра работает сразу после запуска без запроса к GitHub. Доли языков для всех проектов хранятся в каталоге и заданы приблизительно. Активные раунды хранятся в памяти процесса FastAPI.

Над кодом показан граф вызовов. Вокруг выбранной функции расположены её прямые соседи, а стрелки показывают направление вызовов. Поле можно перетаскивать мышью, кнопка «К центру» возвращает его к выбранной функции. Нажатие на узел открывает исходник функции и показывает её связи. Каждый файл запоминает выбранную функцию и прокрутку кода при переключении вкладок. Кнопка «К началу» возвращает к начальному фрагменту выбранного файла. Граф возвращается API отдельно для каждого выбранного узла.

Связи для демо заданы вручную в поле `functions` рядом с фрагментами: имя функции, границы строк и список вызовов. Это ограниченный граф примеров, а не полный индекс репозитория; CodeGraph пока не подключён. У функций вне примеров исходник недоступен, но можно перейти к их известным вызывающим. Пути к файлам скрыты до соответствующей подсказки или ответа.

За языки начисляется до 1000 очков пропорционально совпавшим процентам. Нераспределённая доля `None` очков не даёт. Правильный диапазон звёзд даёт 750 очков. Подсказка показывает точное число звёзд за 750 очков, а список языков без процентов стоит 1000 очков, как подсказка материка.

## Своя карта по GitHub

Вставьте в поле «Своя карта» ссылку на пользователя или организацию GitHub, например `https://github.com/pallets`. Backend загрузит до 60 публичных репозиториев владельца без форков и построит из них новую карту. Материки соответствуют основному языку репозитория, а редкие языки собираются в материк «Другое». Фрагменты кода, доли языков, звёзды и год создания берутся из GitHub в момент начала раунда.

Без токена GitHub API разрешает 60 запросов в час с одного IP. Создание карты стоит 2 запроса, каждый раунд ещё около 2. Чтобы поднять лимит, укажите в `.env` персональный токен в `GITHUB_TOKEN`; права ему не нужны.

Для разработки запустите backend по инструкции в `Backend/README.md`, затем из `Frontend/` выполните `npm ci` и `npm run dev`. Node.js нужен версии 20 или новее. Vite проксирует запросы к API на порт 8000.
